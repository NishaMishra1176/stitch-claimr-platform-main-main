# Stitch Claim Platform

A web-based application developed to simplify the claim management process. The platform provides an easy-to-use interface for managing and tracking claim-related information.

---

## 🚀 Features

- User-friendly interface
- Claim submission and tracking
- Responsive design
- Easy navigation
- Organized project structure
- Fast and lightweight

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- VS Code

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/NishaMishra1176/stitch-claimr-platform-main-main.git
```

2. Open the project in VS Code.

3. Open `index.html` in your browser.

OR

Use the **Live Server** extension in VS Code.
